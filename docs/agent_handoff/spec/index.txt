Mini Project Problem Statements — Index
Course: UE24AM342AA5 — ML System Design and AgentOps
Component: Jackfruit (Level 3), 10 marks | Team size: 2–3 students
Fifteen problem statements. Each team works on one. Technical terms used in all of them are defined in
00_GLOSSARY.pdf.
All fifteen share the same 22 requirements — A1–A8 (agent system), L1–L6 (LLMOps), D1–D8 (platform and
deployment) — the same demonstration list and the same assessment. Only the domain, the corpus and the
functional requirements differ.
The difficulty in each project is agentic by construction. The case in section 4.1 cannot be resolved by a single
retrieval pass, because the provision that decides the outcome is a modifier the request never mentions. It
requires an agent that searches, establishes that further provisions may apply, searches again, and verifies its
own output.
Every corpus is free to download from a regulator, ministry, university or open-source project.
